# L.L.M Academy - 부산 2기

본 Repository는 L.L.M Academy 부산 2기 수강생들의 프로젝트 수행을 위한 공간입니다.

## 📌 이용 방법
1. 본 Repository 우측 상단의 `Fork` 버튼을 클릭합니다.
2. 본인의 GitHub 계정을 Owner로 선택하여 Fork를 생성합니다.
3. Fork한 개인 Repository에서 프로젝트를 진행합니다.
4. 개인 및 팀별 폴더 구성은 자유롭게 진행합니다.

## 📌 팀 프로젝트
- 팀 프로젝트는 팀원 간 협의하여 공동 작업 공간을 구성합니다.
- 필요한 경우 팀원을 Collaborator로 초대하여 함께 작업할 수 있습니다.

## ⚠️ 유의사항
- 본 Repository 및 Fork한 Repository는 Public으로 외부에 공개됩니다.
- 개인정보, 비밀번호, API Key 등 민감한 정보는 업로드하지 마세요.
- 프로젝트별 제출 및 평가 방식은 담당 강사의 안내를 따릅니다.

## llm-academy · 만디 팀 학습 폴더

이 폴더는 6주 동안 부산의 지역 브랜드가 관광·지역 경제와 어떤 관계가 있는지 조사하고, 근거가 확인된 분석 보고서와 발표 자료를 만드는 작업 공간입니다. 현재 주제는 이재모피자입니다.

### 폴더 안내

| 위치 | 쓰임 |
|---|---|
| `CLAUDE.md` | 팀의 목표, 작업 선호, 출처 확인 규칙 |
| `keyword-map.md` | 부산 키워드와 근거, 상태 정리 |
| `SOURCE.md` | 제공된 데이터 6개와 해석상 주의점 |
| `inputs/` | 부산 축제 및 한국관광 데이터랩 CSV 6개 |
| `prompts/` | 세 가지 입력 칸을 채워 키워드 맵을 만드는 프롬프트 |
| `examples/` | 근거가 약한 문장과 근거를 제한해 쓴 문장 비교 |
| `research/` | 확인한 출처와 한계를 기록하는 리서치 노트 |

### 시작 순서

1. `CLAUDE.md`의 `[확인 필요: …]`를 확인합니다.
2. `prompts/01-keyword-map.md`의 세 칸을 채우고, CSV 근거를 확인해 `keyword-map.md`를 업데이트합니다.
3. 새로 확인한 주장이나 출처는 `research/_note-template.md`를 복사해 날짜가 들어간 노트로 남깁니다.

### 해석 원칙

- CSV의 숫자는 해당 파일과 출처를 함께 적습니다. 증감률을 사람 수나 매출액으로 바꾸지 않습니다.
- 관광 통계는 부산 전체·지역 단위 자료입니다. 이재모피자 자체의 방문객·매출 자료가 아니므로, 특정 매장이 관광이나 경제 변화를 일으켰다고 단정하지 않습니다.
- 출처가 한 곳뿐이면 “○○ 보도에 따르면”이라고 밝힙니다. 확인하지 못한 항목은 `[확인 필요: …]`로 둡니다.
- 리뷰 데이터를 수집하기 전에는 해당 플랫폼의 이용약관과 허용 범위를 확인합니다.

### 아직 더 확보하면 좋은 자료

현재 구조에서 빠진 필수 파일은 없습니다. 다만 분석을 구체화하려면 이재모피자 자체의 매장별 방문·매출·고용 자료나, 적법하게 사용할 수 있는 리뷰 자료가 추가로 필요할 수 있습니다. 현재 CSV만으로는 이 자료들을 대신할 수 없습니다.
