# 부산 관광 지표의 해석 범위

- 작성: 만디 팀 · 2026-11-12
- 주제: 제공된 한국관광 데이터랩 CSV로 확인할 수 있는 것과 없는 것

## 요약

현재 파일은 부산 관광의 일부 증감률·비율을 보여 주지만, 방문자 절대 인원이나 이재모피자 매장별 성과를 보여 주지는 않습니다.

## 확인한 자료

| 확인 사항 | 파일 근거 | 해석 |
|---|---|---|
| 방문자 지표 | `inputs/datalab_visitors.csv` 엑셀 2행 | `광역지자체 증감률` 값은 0.8. 파일에는 이 값의 분모인 절대 방문자 수가 없음 |
| 관광 진단 지표 | `inputs/datalab_diagnosis.csv` 엑셀 2~6행 | 방문자유입 0.9, 숙박방문자 비율 -1.2, 체류시간 -3.2, 목적지 검색량 -5.8, 관광소비 9.0. 모두 CSV에 기록된 지표 증감률이며 단위와 비교 기준을 원본 화면에서 재확인해야 함 |
| 숙박·체류 지표 | `inputs/datalab_stay.csv` 엑셀 2행 | 숙박방문자 증감률 -1.2, 체류시간 증감률 -3.2. 방문자 수 자체는 아님 |
| 연관 지역 | `inputs/datalab_related_regions.csv` 엑셀 2행 | 첫 데이터 행은 부산 유입 지역으로 경상남도, 비율 64.9. 열 제목에 유입·유출 비율이 표시됨 |
| 유사지역 | `inputs/datalab_similar_regions.csv` 엑셀 2~4행 | 유사지역 목록은 있지만 어떤 기준으로 유사한지 이 파일만으로는 알 수 없음 |

원본 안내: [한국관광 데이터랩](https://datalab.visitkorea.or.kr/datalab/portal/main/getMainForm.do). 기존 `SOURCE.md`에는 내려받은 분석 기간이 2025-11~2026-10이라고 기록되어 있으나 원본 다운로드 파일이 현재 폴더에 없어 기간은 별도 확인이 필요합니다.

## 교차검증과 주의

- `datalab_visitors.csv`의 `광역지자체 증감률`과 `datalab_diagnosis.csv`의 `방문자유입`은 파일과 항목명이 다릅니다. 각각 0.8과 0.9로 기록되어 있으므로 하나의 지표로 합치지 않습니다.
- 수치의 기준 시점·분모를 원본 다운로드 화면에서 확인하지 못한 부분은 `[확인 필요: 한국관광 데이터랩 원본 화면의 지표 설명과 비교 기간]`으로 둡니다.
- 이 수치를 이재모피자 이용자 수나 매장 성과로 설명할 근거는 없습니다. 매장별 자료가 추가되기 전에는 부산 전체의 관광 맥락으로만 씁니다.

## 더 알아볼 것

- 한국관광 데이터랩에서 각 지표의 정의, 비교 기간, 단위를 다시 확인합니다.
- KKday가 보도자료나 홍보물에 제시한 대만 관광객 수치의 원자료를 찾습니다.
- 매장별 방문·매출 자료가 공개되어 있는지 확인합니다.
